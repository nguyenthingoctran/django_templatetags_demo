Variables

Trong SCSS có thể sử dụng các kiểu biến như sau:

  • strings
  • numbers
  • colors
  • booleans
  • lists
  • nulls
1. Syntax
$variablename: value;
2. Basic Uses

HTML

<h1 id="text-demo-varibles">Demo cho phần Variables</h1>

SCSS

$myFont: fantasy;
$myColor: red;
$myFontSize: 18px;

#text-demo-varibles {
  font-family: $myFont;
  color: $myColor;
  font-size: $myFontSize;
}

CSS render

#text-demo-varibles {
  font-family: fantasy;
  color: red;
  font-size: 18px; }

3. Variable Scope

Khi khai báo variables trong 1 block scss thì variable này sẽ có độ ưu tiên cao trong block. Biến global sẽ không ưu tiên.

HTML:

<h1 id="h1-varibles-scope">Demo cho phần Variables Scope</h1>
<p id="p-variables-scope">Paragraph Variables Scope</p>

SCSS:

$color_1: red;

#h1-varibles-scope {
  $color_1: green;
  color: $color_1;
}

#p-variables-scope {
  color: $color_1;
}

CSS render:

#h1-varibles-scope {
  color: green; }

#p-variables-scope {
  color: red; }

4. Sass !global

HTML:

<h1 id="h1-var-global">Demo cho phần Variables Global</h1>
<p id="p-var-global">Paragraph Variables Global</p>

SCSS:

$color_2: red;

#h1-var-global {
  $color_2: green !global;
  color: $color_2;
}

#p-var-global {
  color: $color_2;
}

CSS render:

#h1-var-global {
  color: green; }

#p-var-global {
  color: green; }
