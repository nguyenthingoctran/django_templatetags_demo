Variables

Trong SCSS có thể sử dụng các kiểu biến như sau:

  • strings
  • numbers
  • colors
  • booleans
  • lists
  • nulls

Syntax

$variablename: value;

HTML:

<h1 id="text-demo-varibles">Demo cho phần Variables</h1>

SCSS:

$myFont: fantasy;
$myColor: red;
$myFontSize: 18px;

#text-demo-varibles {
    font-family: $myFont;
    color: $myColor;
    font-size: $myFontSize;
}

CSS:

$myFont: fantasy;
$myColor: red;
$myFontSize: 18px;

#text-demo-varibles {
    font-family: $myFont;
    color: $myColor;
    font-size: $myFontSize;
}
