1. Trả về thời gian đến May 17, 2050

Data mẫu

        
data = {
  'marslanding': datetime(2050, 5, 17)
}

Render HTML

        
{{ data.marslanding|timeuntil }}

Kết quả

{{ data.marslanding|timeuntil }}
2. Trả về thời gian giữa 2 ngày

Data mẫu

        
data = {
  'marslanding': datetime(2050, 5, 17),
  'moonlanding': datetime(1969, 7, 20)
}

Render HTML

        
{{ data.marslanding|timeuntil:data.moonlanding }}

Kết quả

{{ data.marslanding|timeuntil:data.moonlanding }}
3. Trả về số giờ giữa 2 giờ

data = {
