Syntax

        
{{ value|yesno:"yes,no,maybe" }}

Example

Example Demo Explain
{{ True|yesno:"yes,no,maybe" }} {{ True|yesno:"yes,no,maybe" }} Chuỗi đầu tiên sẽ được trả về nếu input là True
{{ False|yesno:"yes,no,maybe" }} {{ False|yesno:"yes,no,maybe" }} Chuỗi thứ 2 sẽ được trả về nếu input là False
{{ None|yesno:"yes,no,maybe" }} {{ None|yesno:"yes,no,maybe" }} Chuỗi thứ 3 sẽ được trả về nếu input là None
