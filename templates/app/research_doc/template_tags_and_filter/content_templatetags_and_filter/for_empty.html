for … empty
Có thể sử dụng tag empty khi mảng trống hoặc không tìm thấy.

Data mẫu

athlete_list = []

Render HTML

{% for athlete in athlete_list %}
  {{ athlete }}
{% empty %}
  <p class="text-danger">Không có item nào cần hiển thị.</p>
{% endfor %}

Kết quả:

{% for athlete in athlete_list %} {{ athlete }} {% empty %}

Không có item nào cần hiển thị.

{% endfor %}
