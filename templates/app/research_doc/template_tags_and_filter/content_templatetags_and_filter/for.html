For
1. Vòng lặp for được sử dụng để lặp qua một chuỗi, giống như lặp qua các mục trong một array, một list

Data mẫu

                
data = ['Apple', 'Banana', 'Cherry', 'Orange', 'Durian']

Render HTML

                
<ul>
  {% for x in fruits %}
    <li>{{ x }}</li>
  {% endfor %}
</ul>

Kết quả:

    {% for x in fruits %}
  • {{ x }}
    • {% endfor %}
2. Vòng lặp for với dict

Data mẫu

                
dict_cars = {
  'cars': [
    {'brand': 'Ford', 'model': 'Mustang', 'year': 1964},
    {'brand': 'Volvo', 'model': 'XC90', 'year': 2022},
    {'brand': 'Volvo', 'model': 'P1800', 'year': 1962},
    {'brand': 'Ford', 'model': 'Focus', 'year': 2004}
  ]
}

Render HTML

                
{% for x in cars.cars %}
  <h3 class="mb-0">{{ x.brand }}</h3>
  <p>{{ x.model }}</p>
  <p>{{ x.year }}</p>
{% endfor %}

Kết quả:

{% for x in cars.cars %}

{{ x.brand }}

{{ x.model }}

{{ x.year }}

{% endfor %}
3. Vòng lặp từ database

Data mẫu

                
from django.contrib.auth.models import User
users = User.objects.all()

Render HTML

                
{% for x in users %}
  <p>{{ x.id }}) {{ x.first_name }} {{ x.last_name }}</p>
{% endfor %}

Kết quả:

{% for x in users %}

{{ x.id }}) {{ x.first_name }} {{ x.last_name }}

{% endfor %}
4. Vòng lặp ngược

Data mẫu

                
from django.contrib.auth.models import User
users = User.objects.all()

Render HTML

                
{% for x in users reversed %}
  <p>{{ x.id }}) {{ x.first_name }} {{ x.last_name }}</p>
{% endfor %}

Kết quả:

{% for x in users reversed %}

{{ x.id }}) {{ x.first_name }} {{ x.last_name }}

{% endfor %}
5. Empty Array

Data mẫu

                
emptytestobject = []

Render HTML

                
{% for x in emptytestobject %}
  <h3>Not Empty</h3>
{% empty %}
  <h3>Empty</h3>
{% endfor %}

Kết quả:

{% for x in emptytestobject %}

Not Empty

{% empty %}

Empty

{% endfor %}
Note: Từ khoá empty cũng được sử dụng nếu đối tượng không tồn tại
