For
1. Vòng lặp for được sử dụng để lặp qua một chuỗi, giống như lặp qua các mục trong một array, một list

Data mẫu

                
data = ['Apple', 'Banana', 'Cherry', 'Orange', 'Durian']

Render HTML

                
<ul>
  {% for x in fruits %}
    <li>{{ x }}</li>
  {% endfor %}
</ul>

Kết quả:

    {% for x in fruits %}
  • {{ x }}
    • {% endfor %}
2. Vòng lặp for với dict

Data mẫu

                
dict_cars = {
  'cars': [
    {'brand': 'Ford', 'model': 'Mustang', 'year': 1964},
    {'brand': 'Volvo', 'model': 'XC90', 'year': 2022},
    {'brand': 'Volvo', 'model': 'P1800', 'year': 1962},
    {'brand': 'Ford', 'model': 'Focus', 'year': 2004}
  ]
}

Render HTML

                
{% for x in cars.cars %}
  <h3 class="mb-0">{{ x.brand }}</h3>
  <p>{{ x.model }}</p>
  <p>{{ x.year }}</p>
{% endfor %}

Kết quả:

{% for x in cars.cars %}

{{ x.brand }}

{{ x.model }}

{{ x.year }}

{% endfor %}
3. Vòng lặp từ database

Render HTML

{% endfor %}

Kết quả:

{% endfor %}

5. For với key và value

Data mẫu

                
mycar = {
  'car1': {
    'brand': 'Ford',
    'model': 'Mustang',
    'year': '1964'
  }
}

Render HTML

                
{% for x, y in mycar.car1.items %}
  <p>The {{ x }} is {{ y }}.</p>
{% endfor %}

Kết quả:

{% for x, y in mycar.car1.items %}

The {{ x }} is {{ y }}.

{% endfor %}
Một số biến được tích hợp sẵn
Variable Mô tả Code mẫu Kết quả
forloop.counter Trả về index của vòng lặp hiện tại với index bắt đầu bằng 1

Data mẫu

data = ['Apple', 'Banana', 'Cherry', 'Orange', 'Durian']

Render HTML

{% for x in fruits %}
  {{ forloop.counter }}
{% endfor %}
 {% for x in fruits %} {{ forloop.counter }} {% endfor %}
forloop.counter0 Trả về index của vòng lặp hiện tại với index bắt đầu bằng 0

Data mẫu

data = ['Apple', 'Banana', 'Cherry', 'Orange', 'Durian']

Render HTML

{% for x in fruits %}
  {{ forloop.counter0 }}
{% endfor %}
 {% for x in fruits %} {{ forloop.counter0 }} {% endfor %}
