lorem
Dùng hardcode ngẫu nhiên
1. Cú pháp
{% lorem [count] [method] [random] %}

Trong đó:

  • count: số lượng từ hoặc đoạn cần hiển thị. Default là 1
  • method: bao gồm các kiểu hiển thị
    • w: từ
    • p: đoạn văn
    • b: 1 block
  • random: option này biểu thị có hiển thị ngẫu nhiên không.
2. Example

Render HTML. 

{% lorem 3 p random %}

Kết quả:

{% lorem 3 p random %}
