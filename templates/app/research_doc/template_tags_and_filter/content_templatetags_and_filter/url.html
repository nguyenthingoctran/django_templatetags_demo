url
1. Sử dụng URL tag cơ bản

URL file

app_name = '_Extract_Tag'

urlpatterns = [
    path("title/", views.Title.as_view(), name='title')
]

Render HTML

{% url '_Extract_Tag:title' %}

Kết quả:

{% url '_Extract_Tag:title' %}
2. Có thể sử dụng url như 1 biến

Render HTML

{% url '_Extract_Tag:title' as the_url %}

<a href="{{ the_url }}">I'm linking to {{ the_url }}</a>

Kết quả

{% url '_Extract_Tag:title' as the_url %} I'm linking to {{ the_url }}
3. Truyền biến vào URL - Chưa check thực tế.
path("client//", app_views.client, name="app-views-client")
{% url 'app-views-client' client.id %}
