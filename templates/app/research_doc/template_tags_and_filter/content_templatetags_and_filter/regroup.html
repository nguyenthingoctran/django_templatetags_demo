Regroup
Nhóm lại danh sách các đối tượng giống nhau theo một thuộc tính chung.
1. Một số biến có sẵn sử dụng lấy data
  • grouper: mục đang nhóm theo.
  • list: 1 list các item được nhóm.
2. Đối với trường hợp không có dict lồng nhau

Data mẫu

def coder_list_2(self):
  coder_list = [
    {'name': 'Nguyen', 'language': 'Python'},
    {'name': 'Thi', 'language': 'Ruby'},
    {'name': 'Ngoc', 'language': 'JS'},
    {'name': 'Ngoc', 'language': 'C++'},
    {'name': 'Ngoc', 'language': 'Python'},
    {'name': 'Tran', 'language': 'C++'},
  ]
  return coder_list

Render HTML. 

{% regroup coder_list|dictsort:"language" by language as language_list %}
<ul>
  {% for lang in language_list %}
    <li>{{ lang.grouper }}</li>
    <ul>
      {% for item in lang.list %}
      <li>{{ item.name }} - {{ item.language }}
      {% endfor %}
    </ul>
  {% endfor %}
</ul>

Kết quả:

{% regroup coder_list|dictsort:"language" by language as language_list %}
    {% for lang in language_list %}
  • {{ lang.grouper }}
      • {% for item in lang.list %}
    • {{ item.name }} - {{ item.language }}
      • {% endfor %}
    {% endfor %}
3. Đối với trường hợp có dict lồng nhau
{% regroup coder_list_2 by language.lang_name as language_type %}
