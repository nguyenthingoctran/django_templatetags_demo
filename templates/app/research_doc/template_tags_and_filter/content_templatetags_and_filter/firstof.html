Firstof
1. Phần này Output sẽ cho kết quả là giá trị đầu tiên tồn tại, không rỗng, khác False, khác 0.

Data mẫu

                
firstof = [0, "", 'Hello', 'Kitty']

Render HTML

                
{% firstof firstof.0 firstof.1 firstof.2 firstof.3 %}

Phần render HTML tương đương như

                
{% if firstof.0 %}
    {{ firstof.0 }}
{% elif firstof.1 %}
    {{ firstof.1 }}
{% elif firstof.2 %}
    {{ firstof.2 }}
{% elif firstof.3 %}
    {{ firstof.3 }}
{% endif %}

Kết quả

{% firstof firstof.0 firstof.1 firstof.2 firstof.3 %}
2. Trả về kết quả dự phòng nếu tất cả giá trị đều False.

Data mẫu

              
firstof_1 = [0, "", 0]

Kết quả

{% firstof firstof_1.0 firstof_1.1 firstof_1.2 "fallback value" %}

Render HTML. 

                
{% firstof firstof_1.0 firstof_1.1 firstof_1.2 "fallback value" %}
3. Một số cách render phần data dự phòng như HTML

Cách 1: Render HTML với giá trị dự phòng là HTML và tag autoescape 

              
{% autoescape off %}
  {% firstof firstof_1.0 firstof_1.1 firstof_1.2 "<i>fallback value</i>" %}
{% endautoescape %}

Kết quả:

{% autoescape off %} {% firstof firstof_1.0 firstof_1.1 firstof_1.2 "fallback value" %} {% endautoescape %}

Cách 2: Render HTML với giá trị dự phòng là HTML cùng filter

              
{% autoescape off %}
  {% firstof firstof_1.0 firstof_1.1 firstof_1.2 "<strong>fallback value</strong>" %}
{% endautoescape %}

Kết quả

{% firstof firstof_1.0 firstof_1.1 firstof_1.2 "fallback value"|safe %}
