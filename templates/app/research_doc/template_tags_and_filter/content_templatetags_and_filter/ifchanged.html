ifchanged

Có thể sử dụng ifchanged bằng 2 cách

  • TH1: Kiểm tra nội dung hiển thị của chính nó so với trạng thái trước đó và chỉ hiển thị nội dung nếu nó thay đổi.

    Render HTML

    {% for lang in language_program_list %}
  {% ifchanged lang %}
  <hr/>
  {% endifchanged %}
  <b>{{ lang }}</b><br/>
{% endfor %}

    Kết quả:

    {% for lang in language_program_list %} {% ifchanged lang %}
    {% endifchanged %} {{ lang }}
    {% endfor %}

  • TH2: Trong nhiều biến được truyền vào, kiểm tra xem có biến nào đã thay đổi không

    Kết quả:

    {% for coder in coder_list %} {% ifchanged coder.name %}
    {% endifchanged %} {{ coder.name }} - {{ coder.language }}
    {% endfor %}
