if
Tag if đánh giá 1 biến, nếu đúng như điều kiện thì output sẽ là content trong block if
1. Mẫu if thường dùng

Render HTML

{% if athlete_list %}
    Number of athletes: {{ athlete_list|length }}
{% elif athlete_in_locker_room_list %}
    Athletes should be out of the locker room soon!
{% else %}
    No athletes.
{% endif %}

Kết quả:

{% if athlete_list %} Number of athletes: {{ athlete_list|length }} {% elif athlete_in_locker_room_list %} Athletes should be out of the locker room soon! {% else %} No athletes. {% endif %}

Khi 1 biểu thức phức tạp gồm nhiều điệu kiện thì tuân theo quy định ưu tiên từ thấp nhất đến lớn nhất như sau:

  • or
  • and
  • not
  • in
  • ==, !=, <, >, <=, >=
Một số ví dụ cần lưu ý khi sử dụng biểu thức phức tạp

Ta có biểu thức:

{% if a == b or c == d and e %}

Tương đương với

(a == b) or ((c == d) and e)

Không sử dụng như này là sai

{% if a > b > c %}  (WRONG)

Sử dụng như này mới đúng

{% if a > b and b > c %}
