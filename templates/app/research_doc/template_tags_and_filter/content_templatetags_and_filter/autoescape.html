Autoescape
Dùng để show đoạn text chứa HTML
1. Trường hợp khi bật ở chế độ "on"

Data mẫu

data = '{{ autoescape }}'

Render HTML. 

{% autoescape on %}
  <h3>{{ autoescape }}</h3>
{% endautoescape %}

Kết quả:

{% autoescape on %}

{{ autoescape }}

{% endautoescape %}

Note: Trường hợp này có thể dùng cú pháp này để thay thế. Kết quả hiển thị tương tự 

<h1>{{ autoescape|escape }}</h1>
2. Trường hợp khi bật ở chế độ "off"

Data mẫu

data = '{{ autoescape }}'

Trường hợp khi bật ở chế độ "off"

{% autoescape off %}
  <h3>{{ autoescape }}</h3>
{% endautoescape %}

Kết quả:

{% autoescape off %}

{{ autoescape }}

{% endautoescape %}

Note: Trường hợp này có thể dùng cú pháp này để thay thế. Kết quả hiển thị tương tự 

<h1>{{ autoescape|safe }}h1>
