Reduce Right
Xử lý mảng thành 1 giá trị theo yêu cầu từ phải sang trái.

Code mẫu

<h1 id="show-data-reduce-right"></h1>

<script>
  const numbers_reduce = [45, 4, 9, 16, 25];

  let sum = numbers_reduce.reduceRight(function myFunction(total, value) {
    return total + value
  });

  $("#show-data-reduce-right").append(sum)
</script>
