Object Management
1. Thêm hoặc thay đổi 1 Property mới

Syntax

Object.defineProperty(object, property, descriptor)

Code mẫu

<p id="show-data-dp"></p>

<script>
  const person_dp = {
    firstName: "John",
    lastName: "Doe",
    language: "EN"
  };

  // Thêm 1 property mới
  Object.defineProperty(person_dp, 'year', { value: '2008' })
  $("#show-data-dp").append("- Thêm 1 property 'year': " + person_dp.year + "
")

  // Thay đổi property
  Object.defineProperty(person_dp, 'language', { value: 'NO' })
  $("#show-data-dp").append("- Thay đổi giá trị của property 'language': " + person_dp.language)
</script>
