Định nghĩa: Phương thức này trả về các mô tả thuộc tính của một đối tượng.

Code mẫu

<p id="show-data-object-getOwnPropertyDescriptors"></p>

<script>
  const person_5 = {
    firstName: "John",
    lastName: "Doe",
    age: 50,
    eyeColor: "blue"
  }

  let descriptors = Object.getOwnPropertyDescriptors(person_5);
  $("#show-data-object-getOwnPropertyDescriptors").append(descriptors.age.value)
</script>
