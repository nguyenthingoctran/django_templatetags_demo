Định nghĩa: là phương thức ngăn chặn thêm property vào object. Yêu cầu cần sử dụng "use strict" để có thể hiển thị error.

Code mẫu

<p id="show-data-object-preventExtensions"></p>

<script>
  "use strict"
  const person_10 = { firstName: "John", lastName: "Doe" }
  Object.preventExtensions(person_10)

  let text_4 = "";
  try {
    person_10.nationality = "English";
  } catch (err) {
    text_4 = err
  }

  $("#show-data-object-preventExtensions").append(text_4)
</script>
