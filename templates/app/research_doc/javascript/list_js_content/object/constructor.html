Code mẫu

new Object()
new Object(value)

Object()
Object(value)

Với value là bất kỳ giá trị nào.

Ta có các cờ của thuộc tính như sau:

  • writable: true (có thể thay đổi được), read-only (chỉ đọc)
  • enumerable: true (thì thuộc tính xuất hiện trong vòng lặp), false (ngược lại của true)
  • configurable: true (thuộc tính có thể xoá và các cờ khác có thể thay đổi), false (ngược lại của true)
