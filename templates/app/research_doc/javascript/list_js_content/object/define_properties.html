Định nghĩa: Phương thức này có thể thêm hoặc thay đổi properties, property metadata, getters and setters của object.

Syntax

Object.defineProperties(object, descriptors)

Code mẫu

<p id="show-data-dps"></p>

<script>
  const dps_person = {
    firstName: "John",
    lastName: "Doe"
  }

  Object.defineProperties(dps_person, {
    language: { value: "en" },
    year: { value : "Hello" }
  });

  $("#show-data-dps").append(dps_person.language + " " + dps_person.year)
</script>
