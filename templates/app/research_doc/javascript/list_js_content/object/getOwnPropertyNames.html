Định nghĩa: Phương thức này trả về 1 mảng với nhiều properties của 1 object

Code mẫu

<p id="show-data-object-getOwnPropertyNames"></p>

<script>
  const person_6 = {
    firstName: "John",
    lastName: "Doe",
    age: 50,
    eyeColor: "blue"
  }

  let props = Object.getOwnPropertyNames(person_6);
  $("#show-data-object-getOwnPropertyNames").append(props[0])
</script>
