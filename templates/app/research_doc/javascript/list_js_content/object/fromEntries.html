Định nghĩa: Phương thức này tạo 1 đối tượng từ danh sách các cặp khoá/giá trị

Code mẫu

<p id="show-data-object-fromEntries"></p>

<script>
  const fruits_2 = [
    ['apples', 300],
    ['pears', 900],
    ['bananas', 500]
  ]

  const myObj_1 = Object.fromEntries(fruits_2);
  $("#show-data-object-fromEntries").append(myObj_1.pears)
</script>
