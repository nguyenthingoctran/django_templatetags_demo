Định nghĩa: Phương thức này

  • Ngăn chặn việc thêm hoặc xoá các thuộc tính mới
  • Làm cho các thuộc tính hiện có không thể cấu hình được
  • Tự động lỗi ở chế độ non-strict
  • Khi ở chế độ use-strict sẽ trả về lỗi TypeError

<script>
  "use strict"

  const person_11 = {
    firstName: "John",
    lastName: "Doe",
    age: 50,
    eyeColor: "blue"
  }

  Object.seal(person_11);
  let text_5 = "";
  try {
    delete person_11.age;
  } catch (err) {
    text_5 = err;
  }

  $("#show-data-object-seal").append(text_5)
</script>
