Định nghĩa: Phương thức này gom nhóm các thành phần của object theo các giá trị chuỗi trả về một hàm gọi lại.

Code mẫu

<p id="show-data-object-groupBy"></p>

<script>
  const fruits_4 = [
    { name: "apples", quatity: 300 },
    { name: "bananas", quatity: 500 },
    { name: "organges", quatity: 200 },
    { name: "kiwi", quatity: 150 },
  ];

  function myCallback({quatity}) {
    return quatity > 200 ? "ok" : "low";
  }

  const result = Object.groupBy(fruits_4, myCallback);
  const result_stringify = JSON.stringify(result.ok)

  $("#show-data-object-groupBy").append(result_stringify)
</script>
