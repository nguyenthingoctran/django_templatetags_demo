Định nghĩa: Đây là một thuộc tính toàn cục có sẵn trong tất cả các đối tượng JS. Prototype property cho phép bạn thêm các thuộc tính và phương thức mới vào các đối tượng.

Code mẫu

<p id="show-data-object-prototype"></p>

<script>
  function employee(name, jobtitle, born) {
    this.name = name;
    this.jobtitle = jobtitle;
    this.born = born;
  }

  employee.prototype.salary = 2000;
  const fred = new employee("Fred Flintstone", "Caveman", 1970);
  $("#show-data-object-prototype").append(fred.salary)
</script>
