Định nghĩa: Trả về mảng vừa key/value thành 1 cặp object

1. Example 1

Code mẫu

<p id="show-data-object-entries"></p>

<script>
  const person_2 = {
      firstName: "John",
      lastName: "Doe",
      age: 50,
      eyeColor: "blue"
  }

  let text_2 = Object.entries(person_2);
  $("#show-data-object-entries").append(text_2)
</script>

2. Example cho loop được đơn giản hơn.

Code mẫu

<p id="show-data-object-entries-2"></p>

<script>
  const fruits_1 = { Bananas: 300, Oranges: 200, Apples: 500 };

  let text = "";
  for (let [fruit, amount] of Object.entries(fruits_1)) {
    text += fruit + ": " + amount + "
"
  }

  $("#show-data-object-entries-2").append(text)
</script>

3. Chuyển một Object thành Map.

Code mẫu

<p id="show-data-object-entries-3"></p>

<script>
  const fruits_3 = { Bananas: 300, Oranges: 200, Apples: 500 };
  const myMap = new Map(Object.entries(fruits_3))
  document.getElementById("show-data-object-entries-3").innerHTML = myMap;
</script>
