Map
Phương thức map() tạo một mảng mới bằng cách thực hiện một hàm trên mỗi phần tử mảng.

Code mẫu

<p id="show-data-map">


<script>
  const numbers1_map = [45, 4, 9, 16, 25];
  const numbers2_map = numbers1_map.map(function myFunction(value, index, array){
    return "value: " + value + " index " + index + " array " + array + "
"
  });

  $("#show-data-map").append(numbers2_map)
</script>
